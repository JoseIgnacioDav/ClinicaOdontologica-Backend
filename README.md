# ClinicaOdontologica-Backend
Backend modular y seguro desarrollado en Java con Spring Boot para una clínica odontológica, optimizado para la gestión eficiente de citas y control de usuarios.
Implementa arquitectura orientada a servicios, separación estricta de DTOs y encriptación de credenciales para garantizar la privacidad de los datos.
Soluciona la exposición innecesaria de información sensible mediante transformaciones limpias y preprocesamiento de respuestas en el servidor.
Resuelve el problema de la sobrecarga de consultas y el filtrado de entidades relacionales hacia la interfaz de usuario.
Ofrece una base robusta, escalable y orientada a buenas prácticas para el agendamiento médico y futuros despliegues en producción.
